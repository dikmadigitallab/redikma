# Checkpoints - ReDikma

Este arquivo mantém o registro de todos os commits do projeto para permitir retorno a qualquer ponto do desenvolvimento.

---

## Como usar

Para voltar a um checkpoint específico:
```bash
git checkout <commit-hash>
```

Para criar uma branch a partir de um checkpoint:
```bash
git checkout -b <nova-branch> <commit-hash>
```
